Project AEGIS - Standalone Windows Installation
==============================================

✅ SUPER SIMPLE INSTALLATION - 3 STEPS ONLY!

Step 1: System Requirements Check
---------------------------------
- Windows 10 or Windows 11 (64-bit)
- At least 2GB RAM
- 100MB free disk space
- Internet connection (for first run only)

Step 2: Installation
--------------------
1. Extract this ZIP file to any folder
   Example: C:\AEGIS or Desktop\ProjectAEGIS

2. Double-click "Run-AEGIS.bat"
   - This will automatically:
     * Check for Node.js (install if missing)
     * Install required dependencies
     * Start the system
     * Open browser automatically

Step 3: Use the System
----------------------
1. Browser will open automatically at: http://localhost:3000
2. Use the web interface to:
   - Start/Stop the trading engine
   - Monitor system performance
   - View real-time metrics
3. For Arabic interface: http://localhost:3000/ar

📱 MOBILE ACCESS:
----------------
From any device on the same WiFi network:
1. Find your computer's IP address:
   - Press Windows+R, type "cmd", press Enter
   - Type: ipconfig
   - Find "IPv4 Address" (e.g., 192.168.1.100)
2. On mobile device, open browser and go to:
   http://192.168.1.100:3000

🆘 TROUBLESHOOTING:
------------------
Problem: "Node.js not found" error
Solution: Download Node.js from https://nodejs.org/ and install

Problem: Port already in use
Solution: Edit config/settings.json and change port from 3000 to 3001

Problem: Slow performance
Solution: Close other programs, ensure 2GB+ RAM available
