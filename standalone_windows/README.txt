Project AEGIS - Standalone Windows Version
=========================================

Thank you for your interest in Project AEGIS!

This package contains a simplified version of the Project AEGIS HFT system
designed to run easily on Windows with minimal dependencies.

Contents:
---------
1. Simplified source code (Node.js + SQLite)
2. Pre-configured web dashboard
3. Demo trading simulation
4. Telegram integration
5. Arabic/English language support

System Requirements:
--------------------
- Windows 10/11 (64-bit)
- No additional software installation required
- Works directly after extraction

Quick Start:
------------
1. Extract this ZIP file to any folder
2. Double-click "Run-AEGIS.bat" to start
3. Open your browser and go to: http://localhost:3000
4. Use the web interface to control the system

Features Included:
------------------
✓ Real-time dashboard with performance metrics
✓ Multilingual interface (Arabic & English)
✓ Telegram remote control (optional)
✓ Demo trading mode (safe simulation)
✓ Risk management controls
✓ System monitoring

For full documentation, visit:
https://github.com/your-repo/project-aegis

Note: This is a simplified educational version. The full system requires
the complete development environment as described in the main documentation.
